## Принципы проектирования интерфейса

1. **Inline-first подход** - максимальное использование inline кнопок вместо markup клавиатуры
2. **Контекстность** - кнопки появляются в контексте и не дублируют команды
3. **Минимализм** - только необходимые действия, удаление лишних элементов
4. **Отзывчивость** - мгновенное изменение сообщений без новых сообщений
5. **Информативность** - максимум информации в одном сообщении
6. **Мультиязычность** - автоматический выбор подходящего языка (ru/en)

## Архитектура команд

### Основные команды (видны в подсказках бота)

**Установка через `set_default_commands()`:**

```
/start - Начало работы
/login - Авторизация
/logout - Выход
/grades - Оценки
/stats - Статистика
/sync - Обновить
/settings - Настройки
/help - Помощь
```

**Особенность:** Команды видны в подсказках бота (когда пользователь нажимает на кнопку меню и видит "Команды").

### 4. Статистика

**Callback `stats` или команда `/stats`:**

```
📈 Твоя успеваемость

Средний балл: 4.5
Динамика: ↗ +0.3 (+10%) к прошлому месяцу

Посещаемость: 87%
Пропусков: 2 (Н), 1 (Б)

🏆 Лучшие предметы:
1. Программирование - 9.0
2. БД - 8.5
3. Сети - 7.8

📉 Требуют внимания:
1. Математика - 3.0
2. Физика - 2.5

[◀️ Назад]
[📊 Оценки] [📊 График]
[🔄 Обновить]
```

**При нажатии "График":**

Текущее сообщение удаляется. Отправляется изображение с графиком динамики среднего балла по месяцам/неделям и таким же текстом.

## Поведение inline кнопок

### Callback Answer (уведомление при нажатии)

**Используется для:**
- Подтверждения действия в настройках ("✅ Сохранено")
- Сообщений об ошибке ("❌ Ошибка")
- Уведомлений о загрузке ("⏳ Загружаю...")

**Отображение:** Toast-уведомление в Telegram (на 3-5 секунд)

### Edit Message (изменение сообщения)

**Используется для:**
- Обновления таблицы оценок
- Изменения текста в настройках
- Навигации между экранами (без нового сообщения)

**Преимущество:** Чистая лента, нет дублирования сообщений

### New Message (новое сообщение)

**Используется для:**
- Уведомлений о новых оценках
- Результатов экспорта
- Месячных дайджестов
- В ответ на команды `/*`

## Таблицы и форматирование

### Таблица оценок

**Оптимальная ширина:**
- Название предмета: 20 символов (обрезается с `...`)
- Дата: 5 символов (дд.мм)
- Оценка: 1 символа
- Средний балл: 3 символа (X.X)
- Минимальный отступ от контента до разделителя 1 символ

**Пример:**

```
Программирование │ 30.09 │ 10.10 │ 20.10 │ Ср.
─────────────────┼───────┼───────┼───────┼─────
Математика       │   5   │   4   │   -   │ 4.5
─────────────────┼───────┼───────┼───────┼─────
Физкультура ...  │   Н   │   Н   │   8   │ 5.3
```

### Легенда значений

```
- (пусто) = не выставлена
Н = отсутствие
Б = болезнь
О = опоздание
У = уважительная причина
```

## Emoji использование

**Навигация:**
- `[◀️ Назад]` - вернуться на уровень выше
- `[📊 Оценки]` - перейти к оценкам
- `[📈 Статистика]` - перейти к статистике

**Действия:**
- `[🔄 Обновить]` - синхронизация
- `[📥 Экспорт]` - экспорт данных
- `[⚙️ Настройки]` - открыть настройки
- `[🚪 Выход]` - logout

**Статусы:**
- `✅` - успешно, включено
- `❌` - ошибка, отключено
- `⏳` - загрузка, ожидание
- `👁` - режим ожидания
- `ℹ️` - информация
- `⚠️` - предупреждение
- `📬` - уведомление немедленно
- `⏰` - уведомление с задержкой
- `🌙` - ночной режим

## Производительность интерфейса

### Времена отклика

| Действие | Время |
|----------|-------|
| Показать оценки | < 100ms |
| Нажать на предмет | < 100ms (из БД) |
| Обновить оценки (callback) | 1-3 сек (синхронизация) |
| Изменить настройку | < 50ms |
| Экспорт (Excel) | 2-5 сек (Celery task) |

### Ограничения

- **Максимум строк в таблице:** 10 (если больше, показывать выбор предметов)
- **Максимум столбцов в таблице:** 6 (последний = средний балл)
- **Максимум inline кнопок:** 5 в ряду (Telegram ограничение)
- **Максимум текста в сообщении:** 4096 символов

## Стандартизация

### Шаблон сообщения

```
[EMOJI] [ЗАГОЛОВОК]

[ОСНОВНАЯ ИНФОРМАЦИЯ]

[ТАБЛИЦА/ДАННЫЕ] (опционально)

[INLINE КНОПКИ]
```

### Шаблон уведомления

```
[EMOJI] [СОБЫТИЕ]

[ДЕТАЛИ]

[ДЕЙСТВИЯ] (опционально)

[CALLBACK КНОПКИ]
```

### Цветовая схема (emoji)

- **Зелёный:** ✅ успех
- **Красный:** ❌ ошибка, ⚠️ предупреждение
- **Жёлтый:** ⏳ ожидание, 🌙 ночь
- **Синий:** 📊 данные, 📈 статистика
- **Оранжевый:** 📝 оценка, 🔔 уведомление

---

## Тестирование интерфейса

**Чек-лист перед выпуском:**

- [ ] Все сообщения отображаются корректно (не обрезаются)
- [ ] Кнопки расположены логически и не переполняют экран
- [ ] Все inline кнопки работают (callback отправляется)
- [ ] Edit message не создаёт дублей сообщений
- [ ] Таблицы выровнены и читаемы
- [ ] Emoji отображаются корректно на всех платформах
- [ ] Обработка ошибок показывает понятные сообщения
- [ ] Нет информационной перегрузки (макс 3-4 блока на экран)
- [ ] Переходы между экранами интуитивны (◀️ Назад работает везде)
- [ ] Производительность < 100ms на всех операциях
