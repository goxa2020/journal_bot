## Почему архив, а не удаление

- В `technical-bot-architecture.md` есть проверенные детали API и алгоритм группового
  кеширования с подгруппами — они переиспользованы в новых документах.
- В `bot-interface-architecture.md` лежат проработанные тексты и структура экранов, которые
  понадобятся начиная с фазы 2.
- В `dev-plan.md` есть полный чек-лист перед production — он вошёл в ROADMAP в переработанном виде.
