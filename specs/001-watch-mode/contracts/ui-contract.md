# Contract: экран и нажатия режима ожидания

Договор между хендлером, клавиатурой и строками локализации. Меняется только вместе
с тестами хендлера.

## Точки входа

| Откуда | Что приходит | Ожидаемое поведение |
|---|---|---|
| Главное меню (`bot/keyboards/inline/menu.py`) | `callback_data="watch"` | открыть экран режима |
| Экран режима | `watch:extend` | продлить период |
| Экран режима | `watch:off` | выключить досрочно |
| Экран режима | `watch:refresh` | перерисовать экран (обновить остаток) |
| Экран режима | `watch:menu` | вернуться в главное меню |

Регистрация: `bot/handlers/callback/watch.py`, `router` подключается там же, где остальные
callback-роутеры. Значение `"watch"` **удаляется** из `STUB_CALLBACKS`
(`bot/handlers/callback/stubs.py`), иначе обработчик-заглушка перехватит нажатие.

## Экраны

### Выключен

```text
👁 Режим ожидания выключен

Включите его, чтобы бот проверял журнал каждые 5 минут в течение 30 минут
и сразу присылал новые оценки.

[ Включить ]   [ Главное меню ]
```

### Активен

```text
👁 Режим ожидания включён
Осталось: 28 мин

Бот проверяет журнал каждые 5 минут. Новые оценки придут уведомлением.

[ Продлить ]   [ Выключить ]
[ Обновить ]   [ Главное меню ]
```

### Отказ без авторизации

```text
Сначала войдите в журнал edu-tpi — без этого проверять нечего.
[ Войти ]   [ Главное меню ]
```

Переход «Войти» — существующий сценарий входа (тот же `callback_data`, что у кнопки входа).

## Правила текста

- Остаток — целое число минут (`осталось 1 мин`, `осталось 30 мин`), никогда не отрицательный.
- Числа 30 и 5 подставляются из настроек, а не пишутся в `.po`.
- `edit_message_text` с `reply_markup` обязателен: экран обновляется на месте, без новых
  сообщений в чате (причина падений `ValidationError` в прошлых фазах — reply-клавиатура).
- Все строки — ключи `watch.*` в `bot/locales/{ru,en}/LC_MESSAGES/messages.po`, обе локали
  в одном коммите.

## Ключи локализации

| Ключ | Назначение |
|---|---|
| `watch.title_off` | заголовок выключенного режима |
| `watch.title_on` | заголовок активного режима |
| `watch.left` | «Осталось: {minutes} мин» |
| `watch.hint_off` | пояснение, зачем включать (подставляет `{tick}` и `{minutes}` из настроек) |
| `watch.hint_on` | пояснение, что происходит сейчас (подставляет `{tick}`) |
| `watch.enable_btn` | «Включить» |
| `watch.extend_btn` | «Продлить» |
| `watch.off_btn` | «Выключить» |
| `watch.refresh_btn` | «Обновить» |
| `watch.menu_btn` | «Главное меню» |
| `watch.enabled_alert` | всплывающее подтверждение включения |
| `watch.disabled_alert` | всплывающее подтверждение выключения |
| `watch.not_authenticated` | отказ без авторизации |

## Ответы на нажатия

- Любое нажатие обязано завершаться `callback.answer()` — иначе на кнопке навсегда остаётся
  спиннер; текст всплывающего сообщения — короткий (`watch.enabled_alert` и т.п.).
- Ошибка внутри хендлера не должна оставлять пользователя без ответа: `try/finally` вокруг
  логики, `callback.answer()` в `finally`, если ещё не отвечено.
- Двойное нажатие «Включить» — идемпотентно: второй раз это продление, текст не ломается.
